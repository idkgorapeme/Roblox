## Module `src/games/73903875561291.lua`

Flags: `NIHPull`, `NIHGems`, `NIHSpecial`, `NIHDrop`, `NIHLog`.

- `Show Stats` / `Copy Stats`: all attributes above, parsed StatSheet with every
  upgrade node (level/max/price/squad), counts of special hay, gems, disturbed
  tiles.
- `Highlight Special Hay`: gold AlwaysOnTop highlight on every part in
  `workspace.SpecialHay`. `List Special Hay` / `Copy Special Hay List` prints
  `name | class | x,y,z`. `Teleport To Nearest Special Hay`.
- Gems: `Highlight Gems`, `Teleport To Nearest Gem`, `Grab Nearest Gem`
  (`GemGrab` with model / name / numeric id / index, compares the `Gems`
  attribute before and after).
- Pull: `Auto Pull` loop with `PullCooldown` respected. The pull arguments are
  not in the dump, so `Learn Pull Shape` raycasts the mouse target and tries
  8 plausible `PullRequest` shapes, keeping the one the server answers on
  (`StrawPulled` event). The learned shape is stored in the config and reused.
  Manual `Pull Once`, `Pull shape` dropdown, `Pull Stats`,
  `Select Straw Under Mouse` (moves the game's own `StrawHighlight` marker).
- Deposit: `Deposit All (vent)` teleports to `vent/Vent_Ring` and fires
  `DropAllRequest`; `Auto Deposit When Full` does it at `Carrying >= CarryCap`.
- Upgrades: `Upgrade node` dropdown built from `StatSheet.nodes`,
  `Buy Selected Upgrade` (`UpgradeRequest:FireServer(node)`), `Open Upgrade Menu`
  (`OpenUpgrades`), `Show Upgrade Nodes`.
- Needle: `Check Needle State`, `Highlight Needle` (any BasePart with "needle"
  in the name, including `DomeCleared/NeedlePreview`), `Grab Needle`
  (`NeedleGrab`), `Pedestal Prompt`, `Group Reward Prompt`.
- Diagnostics: traffic logger for outgoing `FireServer`/`InvokeServer` on
  `HaystackRemotes` plus every `OnClientEvent`, last update payloads,
  `Dump Remotes` (writes `BrainrotPolice/needle_haystack.txt`),
  `Dump Module Data` (require of HaystackConfig, HayKinds, StrawGroups,
  StrawGroupTree, DugTiles, HaystackStats, StatSheet, HaystackSlots...),
  manual remote tool with parsed arguments.

Raycasts exclude the character, CullShield, CullBacking, SkyWall,
ContainmentShell and the game's own StrawHighlight so wall hits cannot be
mistaken for straw.
