## Notes

- Different remote family from the other three brainrot games: everything is
  a flat `ReplicatedStorage.Remotes.<Name>Event`, no `Request*` naming.
- The game already ships automation of its own: `AutoSellEvent`,
  `AutoBuyEvent`, `AutoDigEvent`, `SetAutoSwingEvent`. Those are probably
  toggles the server keeps as state, so a single call may be enough instead
  of a loop. Needs a spy capture to see the args.
- `Carry` / `CarryCount` / `Capacity` attributes mean carrying is limited,
  a farm loop has to sell or place before the cap is hit.
- `LastZone` / `HighestZone` = 8 with 8 `ZoneGuiPart`s, so zones gate
  progression like worlds do elsewhere.
- Mining loop is likely `SpawnBlockEvent` -> `DamageBlockEvent` ->
  `OpenBlockEvent`, with `SetAutoSwingEvent` / `AutoDigEvent` as the
  built-in shortcut.
- `StealBrainrotEvent` / `StealEvent` / `StealWoodEvent` target other
  players' bases.
