## Module `src/games/113591676283798.lua`

Flags: `WDPCollect`, `WDPHighlight`, `WDPCars`, `WDPTag`, `WDPLog`.

- `Scan Lot`: car count, attribute keys, rare attribute keys (<=12 cars),
  mutated cars, cars whose child set differs from the normal 8 parts, visuals
  folder contents, all collectibles, NearbyCarTag text, State folder children.
- `Dump State Folder`: recursive dump of `ParkingGame.State` + player stats.
- `Read Game Modules`: pcall `require` of Config, CarCatalog, CarModels,
  MutationIndex, CarMutations, CarEscapeConfig, MainShopCatalog,
  PermanentUpgrades, GlobalEventCatalog, CityLayout and shallow dumps them.
- `Highlight All Cars`: blue, mutated purple, within 250 studs.
- `Highlight Mutated Cars`: purple, 0.35 transparency.
- `Watch Nearby Car Tag`: prints `NearbyCarTag.CarLabel.Text` whenever it
  changes, plus nearest car name / distance / mutation.
- `Auto Collect`: valuables (prompt + clickdetector) and gem drops, nearest
  first, teleport, 20 s retry per object.
- `Highlight Collectibles`: gold valuables, cyan gem drops.
- `Log Remote Traffic`: `__namecall` hook on `FireServer`/`InvokeServer` for
  `ParkingGame.*`, `ParkingGlobal`, `ParkingAdmin.Request`; also logs
  `OnClientEvent`. Saved to `BrainrotPolice/parking_traffic.txt`.
- `Show/Copy Last Update Payloads`: keeps the last 30 `Update` payloads.
