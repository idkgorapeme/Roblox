## Game loop (public description)

- Lot with many cars, find the one unlocked car.
- Checking a wrong car eliminates it for everyone.
- Cash and valuables are scattered around the lot.
- Upgrades: search speed/radius, walk speed, drones.
- Gems are the premium currency.

## Module `src/games/113591676283798.lua`

Flags: `WDPAuto`, `WDPHighlight`, `WDPLog`.

- `Scan Parking Lot`: walks `ParkingWorld`, `LocalParkingVisuals`, `LocalCity`;
  reports class counts, prompt texts/hosts, clickdetectors, model names,
  attribute keys + value distribution, cash-like instances, ParkingGame tree,
  player stats. Writes `BrainrotPolice/parking_scan.txt`, copies to clipboard.
- `Find Odd Cars`: two-pass attribute signature scan. Ignores high-cardinality
  attributes (car ids), builds signatures from stable keys, highlights models
  whose signature is unique/rare. This is the main guess at finding the
  unlocked car client-side.
- `Dump Structure (depth 3)`: tree of the three workspace roots and
  `ReplicatedStorage.ParkingGame`.
- `Auto Interact`: nearest ProximityPrompt / ClickDetector, optional teleport,
  configurable delay. Fires prompts and clickdetectors.
- `Highlight Interactables`: colors prompts red (unlock/drive/open/claim/win),
  gold (cash/gem/etc), green (check/inspect/search), blue (other).
- `Log Remote Traffic`: hooks `__namecall` for `FireServer`/`InvokeServer` on
  `ParkingGame.*` + `ParkingGlobal`, and listens to `OnClientEvent`. Writes
  `BrainrotPolice/parking_traffic.txt`. Use while checking one car by hand.
