## Module `src/games/103168011197605.lua`

Flags: `SDSit`, `SDClaim`, `SDLog`.

- `Show Stats` / `Copy Stats`: IQ, precision, streak, wins, coins, hints, inks,
  multiplier, chair, blaster, kill effect, freezes, revives, sabotages, scares,
  playtime, passes, plus the table list.
- Tables: `List Tables` prints every table with category, hard flag, seat
  occupancy, status and pool domain. `Category` dropdown (built from the real
  CategoryLabel values), `Hard mode only`, `Only empty tables`,
  `Sit At Best Table`, `Auto Sit`, `Stand Up`.
  Scoring prefers hard mode, empty seats and small party size.
- Chairs: `List Chairs` (id, name, price, prompt state), `Chair` dropdown,
  `Buy Selected Chair` (teleports and fires `BuyPrompt`), `Teleport To Selected
  Chair`.
- Rewards: `List GUI Buttons` prints every TextButton/ImageButton in
  SizeDuelDaily / SizeDuelPlaytime / SizeDuelRewards, `Click Claim Buttons`
  activates the ones whose text/name contains claim / collect / reward / open,
  `Auto Claim Rewards` repeats every 20 s.
- Diagnostics: `Log SizeDuel.Event` (outgoing FireServer hook + incoming
  OnClientEvent), `Copy Event Log`, `Fire SizeDuel.Event` (no args),
  `Dump Modules` (requires Shop, Rewards, Daily, DailyRewards, Playtime,
  PlaytimeRewards, Products, RobuxShop, Cosmetics, Spectate, ... and prints the
  exported tables), `Copy Last Report`.
