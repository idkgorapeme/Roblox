# Press Key to Drop! (PlaceId 111746173942635)

Roblox page: https://www.roblox.com/games/111746173942635/Press-Key-to-Drop
Creator: Press Key to Drop!

Loop: buy and place keys on your keyboard -> press the keycaps -> balls drop
through the plinko board -> cash. `leaderstats`: `Money` (abbreviated, "1K"),
`Rebirths` (0).

## Module `src/games/111746173942635.lua`

Flags: `PKPress`, `PKCollect`, `PKRebirth`, `PKClaim`, `PKSpin`, `PKLog`.

- Keys: `Auto Press Keys` steps on the nearest keycap within `Search radius`
  inside your own plot (`IsInsideOwnPlot` gate), with a per-key 1.2 s retry and
  configurable `Press delay`. `Press Nearest Key`,
  `List Plots And Key Counts`, `Try In-Game Auto Key Farm`
  (`KeyboardSystem.AutoKeyFarmAction` with Enable/enable/true/Toggle/Start/Auto,
  reports `AutoKeyFarmUnlocked`).
- Money: `Auto Collect` (`RF/Collect` every second, compares the parsed Money
  string), `Collect Now`, `Auto Rebirth` (`RF/Rebirth`), `Rebirth Now`.
- Rewards: `Claim Everything Once` and `Auto Claim Rewards` covering
  `RF/ClaimDailyReward`, `RF/ClaimGroupReward`, `RF/OfflineEarningsAction`,
  `PlaytimeRewardAction`, `DailyQuestAction`, `QuestAction`, `PotionAction`,
  each gated on its attribute (`DailyRewardAvailable`,
  `PlaytimeRewardAvailableCount`, `DailyQuestClaimableCount`,
  `PotionTokenCount`, `OfflineEarningsWindowOpen`). `Auto Spin` /
  `Spin Now` (`RequestSpin` + `ClaimSpinReward`).
- Upgrades: `Upgrade id / node id` textbox, `Buy Upgrade`
  (`RF/PurchaseUpgrade(id)`), `Buy Skill Tree Node`,
  `Buy Player Skill Node`, `Unlock Ball Drop Level`, `Change Plinko World`,
  `Prestige`.
- Keyboard/shop: `Quick Stack`, `Equip Best Brainrots`, `Sell Slot`,
  `Pickup Slot`, `Open Key Shop`, `Keyboard Orders`.
- Codes/travel: `Redeem Code` (`RF/RedeemCode`), `TeleportRequest`,
  `Request Rejoin`.
- Diagnostics: `Dump Configs` (require of every Config module + Shared plot
  utils, writes `BrainrotPolice/presskey_config.txt`), traffic logger for all
  net + feature remotes, last server events, copy helpers, and a manual net
  remote tool with parsed arguments.
- Cmdr and the AdminAbuse remotes are intentionally not wired up.
