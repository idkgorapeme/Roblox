## Module `src/games/110954432401277.lua`

Flags: `NIHDaily`, `NIHGroup`.

- `Show Stats` / `Copy Stats`: gems, class + slots, daily status with countdown,
  group reward state, ActiveRun, volumes, personal bests, ranks.
- `Claim Daily Gems`: `GemDailyClaim:InvokeServer()`, compares the `Gems`
  attribute before/after and prints the delta.
- `Auto Claim Daily`: polls `DailyClaimable` and `DailyNextAt` (unix time) every
  5 s and claims as soon as the server flips it.
- `Claim Group Reward`: `GroupReward.HayPlinth` -> `GroupRewardPrompt`, teleport
  to it, zero the hold time and fire.
- `Auto Claim Group Reward`: fires when `GroupRewardState` is
  `claimable`/`ready`/`unclaimed`.
- `Show Class Info`: prints `ClassKey`, `ClassSlots`, names from
  `ReplicatedStorage.Classes` and the raw `ClassAction()` response.
- Class dropdown + `Apply Selected Class`: tries `ClassAction` with
  `("Select", name)`, `("select", name)`, `("SetClass", name)`, `("Equip", name)`
  and `(name)`, printing each server response so the correct shape is obvious.
- `Check Event RSVP` (`EventRsvpCheck:InvokeServer()`) and `RSVP To Event`
  (`EventRsvpDone:FireServer()`).
- `Show Audio Settings` (SfxVolume / MusicVolume attributes).
- Lobby action buttons: `Create Game`, `Cancel Hold`, `Leave Squad`,
  `Membership`, `Rejoin` (all `:FireServer()`).
- `Manual remote tool`: dropdown of all `Lobby.Remotes`, method
  FireServer/InvokeServer, comma separated arguments (numbers, booleans,
  quoted strings and JSON tables are parsed), saved in the config.
- `Dump Remotes` -> `BrainrotPolice/needle_remotes.txt`.
- `Dump Lobby Module Data`: pcall `require` of the lobby modules + `Classes`
  and shallow dump.

No auto-join / auto-create loops, only the two claim automations.
